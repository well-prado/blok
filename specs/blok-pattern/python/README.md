# blok-kernel

The Python kernel of the Blok pattern: nodes with Pydantic contracts, workflows as data, and one small runtime you call from your own FastAPI app, schedule, queue or tool server.

- [../PATTERN.md](../PATTERN.md) is what it follows, on one page.
- [../conformance/](../conformance/README.md) holds the tests it shares with the TypeScript kernel.
- [../README.md](../README.md), "A second language: Python", shows a node and an app.

```bash
uv sync
uv run pytest
```
